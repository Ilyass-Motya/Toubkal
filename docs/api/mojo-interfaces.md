# Toubkal Mojo Interfaces (Internal IPC)

**Status**: Alpha (Unstable)  
**Last Updated**: 2025-10-18  
**Target Stability**: Stable 1.0 (Aug 2026)  
**Audience**: C++ developers, Chromium contributors

⚠️ **Warning**: Internal APIs - may change without notice. Not exposed to extensions or web pages.

---

## Overview

Mojo is Chromium's Inter-Process Communication (IPC) system. Toubkal uses Mojo for communication between the browser process, renderer processes, and utility processes.

**Key Concepts**:

- **Interfaces**: Defined in `.mojom` files (IDL language)
- **Bindings**: Auto-generated C++ code from `.mojom` files
- **Processes**: Browser (privileged), Renderer (sandboxed), Utility (isolated)
- **Security**: Renderers cannot directly call privileged browser APIs

## Mojo Basics

### Process Architecture

```
┌──────────────────────────────────────────┐
│       Browser Process (C++)              │
│  - Privileged operations                 │
│  - ConsentManager, AuditLogger, AI       │
└────────────┬─────────────────────────────┘
             │ Mojo IPC
             ▼
┌──────────────────────────────────────────┐
│     Renderer Process (Sandboxed)         │
│  - Runs web page JavaScript              │
│  - Sends IPC requests to browser         │
└──────────────────────────────────────────┘
```

**Why Mojo?**

- ✅ Type-safe IPC (no manual serialization)
- ✅ Async by default (non-blocking)
- ✅ Security boundary enforcement
- ✅ Chromium-native (proven, stable)

### .mojom File Structure

**Example**: `consent_manager.mojom`

```
module toubkal.mojom;

// Data structures
struct ConsentRequest {
  string action_type;
  string user_id;
  map<string, string> metadata;
};

struct ConsentResponse {
  bool granted;
  int64 timestamp;
  string? expiration;
};

// Interface definition
interface ConsentManager {
  // Request consent from user
  RequestConsent(ConsentRequest request) => (ConsentResponse response);

  // Check if consent already exists
  HasConsent(string action_type, string user_id) => (bool has_consent);

  // Revoke consent
  RevokeConsent(string action_type, string user_id) => (bool success);
};
```

**Generated Files** (auto-generated by Mojo compiler):

- `consent_manager.mojom.h` (C++ header)
- `consent_manager.mojom.cc` (C++ implementation)
- `consent_manager.mojom-shared.h` (shared data types)

## Interface Definitions

### 1. ConsentManager Interface

**File**: `/src/toubkal/common/consent_manager.mojom`

```
module toubkal.mojom;

import "mojo/public/mojom/base/time.mojom";

// Consent scope (session, persistent, etc.)
enum ConsentScope {
  SESSION,       // Until browser closes
  PERSISTENT,    // Until explicitly revoked
  TIME_BOUND     // Expires after duration
};

// Consent request data
struct ConsentRequest {
  string action_type;              // e.g., "AI_QUERY_LOCAL"
  string user_id;                  // Anonymous user ID
  ConsentScope scope;              // Consent duration
  mojo_base.mojom.TimeDelta? ttl;  // Time-to-live (if TIME_BOUND)
  map<string, string> metadata;    // Additional context
};

// Consent response
struct ConsentResponse {
  bool granted;                    // User decision
  int64 timestamp;                 // Unix timestamp (ms)
  string consent_id;               // Unique consent ID
  mojo_base.mojom.TimeDelta? expires_in; // Expiration time
};

// Consent status
struct ConsentStatus {
  bool granted;
  int64 granted_at;
  int64? expires_at;
  ConsentScope scope;
};

interface ConsentManager {
  // Request consent from user (shows UI prompt)
  RequestConsent(ConsentRequest request) => (ConsentResponse response);

  // Check if consent exists (no UI)
  HasConsent(string action_type, string user_id) => (bool has_consent);

  // Get consent status details
  GetConsentStatus(string action_type, string user_id) => (ConsentStatus? status);

  // Revoke consent
  RevokeConsent(string action_type, string user_id) => (bool success);

  // List all active consents for user
  ListConsents(string user_id) => (array<ConsentStatus> consents);
};
```

### 2. AuditLogger Interface

**File**: `/src/toubkal/common/audit_logger.mojom`

```
module toubkal.mojom;

// Audit log entry
struct AuditLogEntry {
  int64 timestamp;                 // Unix timestamp (ms)
  string action_type;              // Action identifier
  string user_id;                  // Anonymous user ID
  map<string, string> data;        // Action-specific data
  string signature;                // Ed25519 signature (hex)
  string merkle_root;              // Merkle tree root hash (hex)
  string? previous_merkle_root;    // Previous root (chain integrity)
};

// Query filters
struct AuditLogQuery {
  int64? start_time;               // Filter by time range
  int64? end_time;
  string? action_type;             // Filter by action type
  uint32 limit = 100;              // Max results
  uint32 offset = 0;               // Pagination offset
};

interface AuditLogger {
  // Log new audit entry (privileged operation)
  LogEvent(string action_type,
           string user_id,
           map<string, string> data) => (AuditLogEntry entry);

  // Query audit logs
  QueryLogs(AuditLogQuery query) => (array<AuditLogEntry> entries);

  // Verify log entry signature
  VerifyEntry(AuditLogEntry entry) => (bool valid);

  // Export all logs (for user data export)
  ExportLogs(string format) => (array<uint8> data);  // JSON or CSV

  // Get Merkle tree root (for integrity verification)
  GetMerkleRoot() => (string root_hash);
};
```

### 3. AIInferenceGateway Interface

**File**: `/src/toubkal/components/ai_platform/gateway.mojom`

```
module toubkal.ai.mojom;

import "toubkal/common/consent_manager.mojom";

// AI model identifier
struct ModelId {
  string engine;    // e.g., "ollama", "transformers_js"
  string model;     // e.g., "llama3.2-3b"
};

// AI query request
struct InferenceRequest {
  string prompt;                   // User query
  ModelId model;                   // Model to use
  map<string, string>? context;    // Additional context (page content, etc.)
  bool stream = false;             // Enable streaming response
};

// AI response
struct InferenceResponse {
  string text;                     // Generated text
  int32 tokens_generated;          // Token count
  int64 latency_ms;                // Inference latency
  ModelId model_used;              // Actual model used
};

// Model info
struct ModelInfo {
  ModelId id;
  string name;                     // Human-readable name
  string type;                     // "local" or "cloud"
  uint64? size_bytes;              // Model size (if local)
  bool requires_api_key;           // For cloud models
  bool available;                  // Downloaded and ready
};

interface AIInferenceGateway {
  // Send inference query (requires consent)
  Query(InferenceRequest request) => (InferenceResponse response);

  // List available models
  ListModels() => (array<ModelInfo> models);

  // Download model (local models only)
  DownloadModel(ModelId model) => (bool success);

  // Remove model
  RemoveModel(ModelId model) => (bool success);

  // Get model status
  GetModelStatus(ModelId model) => (ModelInfo? info);
};
```

### 4. MCPClient Interface

**File**: `/src/toubkal/components/mcp/mcp_client.mojom`

```
module toubkal.mcp.mojom;

// MCP server info
struct MCPServer {
  string id;                       // Server ID (e.g., "toubkal-tabs")
  string name;                     // Human-readable name
  string version;                  // Server version
  array<string> tools;             // Tool names
  bool enabled;                    // Server enabled/disabled
};

// Tool invocation request
struct ToolInvocation {
  string server_id;                // Server to invoke
  string tool_name;                // Tool name
  map<string, string> params;      // Tool parameters (JSON-serialized)
};

// Tool result
struct ToolResult {
  bool success;                    // Invocation succeeded
  map<string, string> result;      // Tool output (JSON-serialized)
  string? error;                   // Error message (if failed)
};

interface MCPClient {
  // List registered MCP servers
  ListServers() => (array<MCPServer> servers);

  // Invoke MCP tool (requires consent)
  InvokeTool(ToolInvocation request) => (ToolResult result);

  // Register new server (from extension)
  RegisterServer(string server_id,
                 string manifest_json) => (bool success);

  // Unregister server
  UnregisterServer(string server_id) => (bool success);

  // Enable/disable server
  SetServerEnabled(string server_id, bool enabled) => (bool success);
};
```

## Usage Examples

### Example 1: Request Consent (Renderer → Browser)

**Renderer Process (JavaScript → C++ binding)**:

```
// renderer_process.cc
#include "toubkal/common/consent_manager.mojom.h"

void RequestAIConsent() {
  mojo::Remote<toubkal::mojom::ConsentManager> consent_manager;
  // Bind to browser process
  GetBrowserInterface(consent_manager.BindNewPipeAndPassReceiver());

  auto request = toubkal::mojom::ConsentRequest::New();
  request->action_type = "AI_QUERY_LOCAL";
  request->user_id = "anon_user_123";
  request->scope = toubkal::mojom::ConsentScope::SESSION;

  consent_manager->RequestConsent(
      std::move(request),
      base::BindOnce(&OnConsentResponse));
}

void OnConsentResponse(toubkal::mojom::ConsentResponsePtr response) {
  if (response->granted) {
    // Proceed with AI query
  } else {
    // Show error to user
  }
}
```

### Example 2: Log Audit Event (Browser Process)

```
// browser_process.cc
#include "toubkal/common/audit_logger.mojom.h"

void LogAIQuery(const std::string& query, const std::string& model) {
  mojo::Remote<toubkal::mojom::AuditLogger> audit_logger;
  GetAuditLogger(audit_logger.BindNewPipeAndPassReceiver());

  base::flat_map<std::string, std::string> data;
  data["query"] = query;
  data["model"] = model;

  audit_logger->LogEvent(
      "AI_QUERY_LOCAL",
      "anon_user_123",
      std::move(data),
      base::BindOnce(&OnAuditLogged));
}
```

### Example 3: Invoke MCP Tool (Browser Process)

```
// ai_gateway.cc
#include "toubkal/components/mcp/mcp_client.mojom.h"

void CloseTabs(const std::string& filter) {
  mojo::Remote<toubkal::mcp::mojom::MCPClient> mcp_client;
  GetMCPClient(mcp_client.BindNewPipeAndPassReceiver());

  auto invocation = toubkal::mcp::mojom::ToolInvocation::New();
  invocation->server_id = "toubkal-tabs";
  invocation->tool_name = "close_tabs";
  invocation->params["filter"] = filter;

  mcp_client->InvokeTool(
      std::move(invocation),
      base::BindOnce(&OnToolResult));
}
```

## Security Considerations

### 1. Privilege Boundaries

**✅ Allowed**:

- Renderer → Browser: `ConsentManager::HasConsent()` (read-only)
- Browser → Utility: `AIInferenceGateway::Query()` (isolated)

**❌ Forbidden**:

- Renderer → Browser: `AuditLogger::LogEvent()` (privileged write)
- Renderer → Browser: `ConsentManager::RevokeConsent()` (user must revoke via UI)

---

### 2. Interface Security Annotations

```
// Privileged interface (browser process only)
[RequireContext=kBrowserProcess]
interface AuditLogger {
  LogEvent(...) => (...);
};

// Safe for renderer process
[AllowedContext=kRenderer]
interface ConsentManager {
  HasConsent(...) => (...);
};
```

---

### 3. Validation

**Always validate Mojo inputs**:

```
void ConsentManagerImpl::RequestConsent(
    ConsentRequestPtr request,
    RequestConsentCallback callback) {
  // Validate action_type
  if (!IsValidActionType(request->action_type)) {
    std::move(callback).Run(ConsentResponse::NewError());
    return;
  }

  // Show UI to user
  ShowConsentDialog(std::move(request), std::move(callback));
}
```

## Building Mojo Interfaces

### Step 1: Add .mojom file

```
/src/toubkal/common/my_interface.mojom
```

### Step 2: Add to BUILD.gn

```
# BUILD.gn
mojom("interfaces") {
  sources = [
    "my_interface.mojom",
  ]

  public_deps = [
    "//mojo/public/mojom/base",
  ]
}
```

### Step 3: Build

```
autoninja -C out/Debug toubkal
```

**Generated files**:

- `out/Debug/gen/toubkal/common/my_interface.mojom.h`
- `out/Debug/gen/toubkal/common/my_interface.mojom.cc`
